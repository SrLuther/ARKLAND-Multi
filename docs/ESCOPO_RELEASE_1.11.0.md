**Objetivo:** reunir em um unico release os pedidos explicitos desta conversa. O release so sera preparado quando todos os criterios obrigatorios passarem. Versoes de plugins continuam independentes da versao do aplicativo.

## Limites

- "Todas as solicitacoes" sao os pedidos explicitos desta conversa, inclusive Web Store, bot, plugin, banco e reestruturacao do gerenciador.
- CustomShop mantem sua propria versao de plugin. 1.10.45 e a versao do plugin instalado no servidor, nao a versao do aplicativo.
- ASM e referencia funcional. A implementacao sera independente em Python; nao portar codigo GPL sem resolver compatibilidade de licenca.
- Os slots 0, 1, 2 e 3 usam uma unica tabela com coluna slot; nao quatro colunas de payload.
- Os arquivos em C:/Users/Ciano/Documents/WindowsServer sao somente leitura e servem como fixtures reais; nunca editar os originais.

## Bloqueios para publicar

1. Nenhum erro critico nos fluxos de vinculo, bonus, auditoria e migracao de cloud inventory.
2. INI e progressao passam testes unitarios, integrados e fixtures representativas.
3. Testes relevantes de app/site/bot/plugins passam; build Windows e instalador verificados.
4. APP_VERSION, version.json, changelog, instalador e release concordam em 1.11.0.
5. Validar pacote final e link antes de publicar.
